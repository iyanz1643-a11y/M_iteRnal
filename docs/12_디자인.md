# 12. 디자인 기준

2026년 11월 13일에 정한 방향이다. 반응형, 인포그래픽, 큰 글씨, 단순하고 직관적인 화면을 목표로 하고, 애플 제품 화면의 형식을 참고한다. 구현은 `app/web/static/app.css` 와 `app/web/templates/_ui.html` 에 있다.

## 1. 원칙

1. **화면마다 주인공 숫자 하나.** 들어오자마자 가장 큰 글씨로 한 가지를 말한다. 설계사 홈은 이번 달 인정보험료, 관리자 홈은 가동률이다.
2. **글로 설명하기 전에 그림으로 보여 준다.** 비율은 고리, 순위는 눈금 위의 점, 비교는 막대로 그린다.
3. **색은 상태를 뜻할 때만 쓴다.** 초록은 정상과 가동, 주황은 확인 필요, 빨강은 차단과 마감 임박이다. 꾸미려고 색을 쓰지 않는다.
4. **여백으로 나눈다.** 선과 테두리 대신 흰 카드와 회색 바탕, 넉넉한 간격으로 구획한다.
5. **한 손으로 쓴다.** 휴대폰에서는 아래 탭 네 개와 더보기로 모든 화면에 닿는다. 누르는 곳은 48픽셀 이상이다.
6. **모르는 것은 모른다고 적는다.** 금액이 원문에만 있으면 숫자를 지어내지 않고 원문 확인이라고 쓴다. 실적에는 기준 시각을 붙인다.

## 2. 글자

| 쓰임 | 크기 | 굵기 |
| --- | --- | --- |
| 화면 제목 | 34~60픽셀. 화면 폭에 따라 변함 | 700 |
| 주인공 숫자 | 40~72픽셀 | 700 |
| 카드 숫자 | 32~48픽셀 | 700 |
| 구획 제목 | 24~32픽셀 | 700 |
| 본문 | 17픽셀. 휴대폰 16픽셀 | 400 |
| 카드 이름표 | 15픽셀 | 600 |
| 보조 설명 | 13~14픽셀 | 400 |

- 글꼴은 기기의 기본 글꼴을 쓴다. 아이폰과 맥에서는 샌프란시스코와 애플 SD 산돌고딕 Neo, 그 밖에서는 프리텐다드나 본고딕으로 보인다. 따로 내려받는 글꼴이 없어 빠르다.
- 큰 글씨는 자간을 조금 좁힌다. 숫자는 자릿수 폭이 같은 숫자로 맞춘다.
- 단위는 숫자의 0.42배 크기로 옆에 붙인다. 한글은 낱말 단위로만 줄을 바꾼다.

## 4. 구성 요소

| 요소 | 모양 | 쓰는 곳 |
| --- | --- | --- |
| 카드 | 흰 바탕, 모서리 22픽셀, 테두리와 그림자 없음 | 모든 묶음 |
| 숫자 카드 | 이름표, 큰 숫자와 단위, 한 줄 설명 | 실적, 운영 상태 |
| 고리 | 비율을 고리로 그리고 가운데에 퍼센트 | 가동률, 목표 달성률, 교육 수료율 |
| 눈금 위의 점 | 꼴찌에서 1위까지의 선 위에 내 자리 | 내 순위 |
| 막대 | 이름, 가로 막대, 값 | 상위 실적, 조직 비교 |
| 프로모션 카드 | 보험사, 마감 표시, 큰 지급률, 이름, 기간과 지급 시점 | 프로모션 |
| 알약 표시 | 둥근 작은 표지 | 가동, 미가동, 마감, 역할 |
| 상태 점 | 이름표 앞의 색 점 | 운영 상태 |
| 표 | 줄 간격이 넓고 가로선만 있는 표 | 목록 |

## 5. 반응형

| 폭 | 기기 | 배치 |
| --- | --- | --- |
| 760픽셀 이하 | 휴대폰 | 한 줄에 카드 하나. 아래 탭. 표에서 덜 중요한 열을 숨김. 프로모션은 옆으로 넘김 |
| 761~1000픽셀 | 태블릿 | 한 줄에 카드 둘. 위 메뉴는 옆으로 넘김 |
| 1001픽셀 이상 | PC | 한 줄에 카드 둘에서 다섯. 위 메뉴와 묶음 안 메뉴 |

- 위 메뉴는 반투명하게 흐려진 띠로 화면 위에 붙어 있다.
- PC 는 위에 묶음, 그 아래에 묶음 안의 화면을 알약 모양으로 둔다. 전체 메뉴 단추로 모든 화면을 한눈에 본다.
- 휴대폰은 아래에 홈, 내 진척, 프로모션, 영업·제안, 더보기를 둔다.

## 6. 인포그래픽 규칙

- 한 화면에 고리는 둘까지만 쓴다. 많으면 무엇이 중요한지 흐려진다.
- 한 줄의 숫자 카드는 휴대폰에서 셋, PC 에서 다섯을 넘기지 않는다.
- 그림에는 반드시 숫자를 함께 적는다. 색과 모양만으로 뜻을 전하지 않는다.
- 조건이 여러 개인 지급률은 숫자 하나로 줄이지 않고 원문 그대로 보여 준다.
- 금액이 가려져야 하는 화면에서는 막대도 그리지 않는다.
