# 06. 프로토타입 실행 (샘플 데이터)

Python + SQLite + Streamlit 으로 만든 동작하는 프로토타입이다. 샘플 데이터는 고정 시드로 생성되므로 몇 번을 돌려도 같은 결과가 나온다.

## 실행

```bash
pip install -r requirements.txt
python run_demo.py          # data/demo.db 생성, 202601~202610 전체 계산, 요약 출력
streamlit run app/ui.py     # 화면 (http://localhost:8501)
```

## 샘플 데이터 구성

| 항목 | 내용 |
|------|------|
| 보험사 | 3곳 (SAM 샘플생명, HAN 한빛손해, DAE 대한생명) |
| 상품 | 보험사당 3종 (종신 환산율 1.0, 건강 0.8, 연금 0.5) |
| 조직 | 서울본부·부산본부, 각 2팀. 설계사 1명은 202607에 본부 이동 |
| 설계사 | 20명, 위촉일·직급(FC/SFC/SM) 다양 |
| 계약 | 202601~202610 약 650건. 202610 에는 청약 중·반송 건 포함, 전체 기간에 철회·실효·해지 섞임 |
| 납입 | 성립 월부터 회차별 납입 (연납은 1회차만) |
| 수수료율 | 보험사 × 상품군 × 유형 × 회차 구간. SAM 종신은 상품 개별 요율(우선순위 10)이 202407부터 덮어씀 |
| 환수율 | 경과 1~6회차 100%, 7~12회차 50%, 13~24회차 20% |
| 시상 규칙 | 월간 환산P 시상(3구간, 유지율·건수 조건, 6개월 환수 감시), 샘플생명 10월 시책(정액 2구간), 분기 시상 |
| 정산서 | 202610 보험사 3곳. 요율 차이·환산 차이·누락 계약·보험사 단독 시책·내부 단독 등 8건의 차이를 일부러 넣음 |
| 커리어 | FC→SFC, SFC→SM 승격 기준, 분기·연 개인 목표 |
| 인증 | MDRT(수수료 기준 OR 보험료 기준), 우수인증설계사(근속·유지율·불완전판매). 기준 값은 **샘플** |

## 파이프라인 (run_demo.py)

```
seed            마스터·계약·납입·유지율·규칙 생성
for 202601..202610:
  commission    납입 회차별 수수료 + 해당 월 실효/해지/철회 환수
  performance   월·분기(누적)·반기(누적)·연(누적) 설계사별 집계
  incentive     월 규칙 적용, 분기 규칙은 분기 말에만, 이전 시상 환수
seed_statements 202610 보험사 정산서 생성 (차이 주입)
reconcile       정산서 ↔ 내부 계산 매칭, 차이 분류
certification   2026년 인증 진척·달성 예상
```

모든 계산은 `calc_run` 단위로 기록되고, 같은 유형·월을 다시 돌리면 이전 run은 `superseded` 가 되어 화면은 항상 최신 완료 run만 보여준다.

## 코드 구성

| 경로 | 역할 |
|------|------|
| `app/db.py` | 연결, 스키마 초기화, run 관리 |
| `app/periods.py` | 기간 키(월/분기/반기/연) 계산 |
| `app/seed.py` | 샘플 데이터 생성, 정산서 차이 주입 |
| `app/engine/commission.py` | 수수료율 규칙 선택(우선순위·적용기간), 초회/계속, 환수 |
| `app/engine/performance.py` | 청약(예정)·성립·철회(차감) 집계 |
| `app/engine/incentive.py` | 자격 조건, 구간, 정률/정액 보상, 시상 환수 |
| `app/engine/reconcile.py` | 매칭 키(보험사·증권·유형·회차), 허용 오차, 차이 유형 분류 |
| `app/engine/career.py` | 승격 후보, 목표 진척 |
| `app/engine/certification.py` | 연 누적 지표, 그룹 OR 기준, 달성 예상 |
| `app/ui.py` | Streamlit 10개 메뉴 |

## 화면에서 해볼 수 있는 것

- **점검(대사)**: open 차이 8건을 보고 상태(confirmed/adjusted/ignored)·담당자·메모를 저장. 감사 로그에 남는다.
- **마감**: 미처리 차이가 남아 있으면 마감 버튼이 잠긴다. 차이를 모두 처리하면 마감된다.
- **수수료 / 구간시상 / 인증**: 재계산 버튼으로 새 run을 만들고 결과가 바뀌는지 확인.
- **업적**: 월/분기/반기/연 전환, 계약 원장 검색(증권·청약번호·설계사명).
- **데이터 수집 → 본부 계약 업로드**: `templates/11_본부계약업로드.csv` 를 올리면 상태별 건수를 미리 보여준다 (적재는 아직 미구현).
