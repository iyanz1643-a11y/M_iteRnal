# 06. 프로토타입 실행 (샘플 데이터)

Python + SQLite + Streamlit 으로 만든 동작하는 프로토타입이다. 샘플 엑셀·PDF 를 만들어 적재기와 PDF 추출기로 실제 파일처럼 읽는다. 고정 시드라 몇 번을 돌려도 같은 결과가 나온다.
엑셀 적재기, PDF 추출, 조직·임원제도·인증의 상세는 `docs/07_엑셀적재_PDF추출_조직_인증.md` 에 있다.

## 실행

```bash
pip install -r requirements.txt
python run_demo.py          # data/demo.db 생성, 202601~202610 전체 계산, 요약 출력
streamlit run app/ui.py     # 화면 (http://localhost:8501)
```

## 샘플 데이터 구성

| 항목 | 내용 |
|------|------|
| 원수사 | 4곳: 샘플생명·대한생명(생명), 한빛손해·미래화재(손해) |
| 상품 구분 | 종신, 건강, 저축, 연금, 재물, 자동차, 일반. 종신·건강만 시상 대상 |
| 조직 | 서울본부(강남·종로지점), 부산본부(해운대·서면지점). 본부장 2명, 지점장 4명 |
| 설계사 | 24명. 1명은 202607 에 다른 본부 지점으로 이동 |
| 본부 계약현황 엑셀 | 본부 × 월 20개. 청약·성립·철회·반송·실효·해지, 공동모집 0.5건 포함. 서울본부 10월 파일에는 품질검증용 문제 행 5개 |
| 유지율 엑셀 | 월별 10개. 원수사별 13·25회차 |
| 시상 공문 PDF | 본사 연간 제도(기본 2 + 추가 1), 샘플생명 10월 시책(기본 1 + 추가 1), 한빛손해 11월 시책(검토 대기) |
| 원수사 정산서 엑셀 | 202610 4개. 양식이 서로 다르고, 요율·환산·누락·단독 지급·상태 불일치 등 차이 10건을 일부러 넣음 |
| 프로그램 | MDRT, 협회 인증 2, 원수사 인증 2, 설계사 임원제도 2, 관리자 임원제도 2, 영업우수설계사, 명예의전당. 기준 값은 **샘플** |

## 파이프라인 (run_demo.py)

```
masters.seed          구분·원수사·상품·조직·관리자·설계사·수수료율·프로그램
samples.*             data/raw/sample/ 에 엑셀 30개 + PDF 3개 생성
pdf_incentive         PDF → 규칙 초안 → 승인 (11월 공문은 검토 대기로 남김)
for 202601..202610:
  load_org_contract   본부 계약현황 엑셀 적재 (청약번호 기준 신규 / 상태변경)
  load_persistency    유지율 엑셀 적재
  payments.accrue     그 달 납입 회차 반영
  commission          수수료 + 환수
  performance         월·분기·반기·연 집계
  incentive           기본·추가시상, 시상 환수
  ranking             전체 설계사 순위
write_statement_files → load_statement   원수사 정산서 엑셀 생성·적재
reconcile             대사
certification         인증·임원제도·어워드 진척
```

모든 계산은 `calc_run` 단위로 기록되고, 같은 유형·월을 다시 돌리면 이전 run 은 `superseded` 가 된다.

## 코드 구성

| 경로 | 역할 |
|------|------|
| `app/masters.py` | 마스터 샘플 |
| `app/samples.py` | 샘플 엑셀·PDF 생성 |
| `app/loader/excel_loader.py` | 배치 등록, 원본 보존, 매핑·변환, 품질검증, 계약·정산서·유지율 적재 |
| `app/loader/transforms.py`, `mapping.py` | 값 변환 규칙, 매핑 YAML 버전 선택 |
| `app/loader/pdf_incentive.py` | 시상 공문 PDF 추출, 초안 저장, 승인·반려 |
| `app/engine/` | payments, commission, performance, incentive, ranking, reconcile, career, certification, persist |
| `app/ui.py` | Streamlit 12개 메뉴 |

## 화면에서 해볼 수 있는 것

- **데이터 수집**: `samples/excel/` 의 계약현황 엑셀을 고쳐 올리면 신규·상태변경 건수가 나온다. 같은 파일을 다시 올리면 막힌다. 추출 8항목을 CSV 로 내려받는다. 품질 이슈를 해결 처리한다. 11월 한빛손해 공문 초안을 검토하고 승인한다.
- **조직**: 본부·지점별 관리자, 인원, 실적, 가동률, 유지율.
- **구간시상**: 구분별 기본·추가시상 유무, 설계사별 기본 + 추가 합계, 시상 환수.
- **랭킹 · 명예의전당**: 전월 순위 공유용 CSV, 연 누적 순위, 수상 이력.
- **점검(대사)**: 차이 10건을 여러 건씩 선택해 처리. 감사 로그에 남는다.
- **인증 · 임원제도**: 분류별 프로그램, 지표별 실적과 충족 여부, 연말 달성 예상.
- **마감**: 차단 품질 이슈, 미처리 차이, 검토 대기 공문이 남아 있으면 잠긴다.
