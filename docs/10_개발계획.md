# 10. 개발 계획

2026년 11월 17일 기준이다. 기능의 상세는 `09_기능기획서.md`, 도구와 구조는 `11_개발구조.md`, AI가 일하는 방식과 에이전트는 `13_AI운영설계.md` 에 있다. 열린 결정은 이 문서의 7장 한 곳에만 둔다.

## 1. 앱 정의와 범위

이터널총괄본부가 보험 계약과 실적을 관리하고, 관리자가 조직의 교육과 진척을 챙기며, 설계사가 자기 진척과 진행 중인 프로모션을 보고 고객 제안까지 이어 가는 업무 앱이다.

| 쓰임 | 내용 |
| --- | --- |
| 관리 | 계약, 실적, 수수료, 시상을 적재하고 점검하고 마감한다 |
| 육성 | 교육 진척도, 커리어패스, 인증, 프로모션 달성 현황을 사람별로 본다 |
| 제안 | DB 배정에서 보장분석 제안 리포트, 카드뉴스, 모바일 명함까지 잇는다 |

하지 않는 것은 세 가지다. 원수사 전산이나 본사 정산 시스템을 대신하지 않는다. 수수료와 시상금을 지급하지 않는다. 공식 광고 심의를 대신하지 않는다.

## 4. 파트별 상태

실제 코드 기준이다. 맡는 에이전트의 이름은 `.claude/agents/` 의 파일 이름이다.

S2 의 C, D, E, F, J 는 11월 15일에 개발을 마쳤다. 커밋은 e3a3c2d 에서 51517b3 까지다. S2 검증에서 세 역할이 휴대폰으로 주요 화면을 쓰는 것을 확인했다. 5장의 S2 기준 가운데 남은 것은 대표님의 한 달 시범 운영이다. 시범 운영에는 지금 조직의 계약현황 D-69 와 시범 운영 장소가 필요하다. 장소는 D-14 에 함께 적었다. 실제 사원현황은 D-02 로 받았다.

S3 는 11월 15일에 개발을 마쳤고 실제 배포 D-14 를 기다린다. 커밋은 35ca48d, c19c548, 2a8f340, 809657f, 8986070, d3f5088, 37a36f1 이다. 된 것은 A 의 세션 끊기와 횟수 제한, B 와 G 의 웹 이관, H 조직별 설정, J 의 명함 연동 3차, K 의 운영 기반, D 의 확정 기능이다. D 의 확정 기능은 엔진에 이어 4d9e0d0 에서 화면까지 마쳤다. S3 검증은 통과했다. 샘플 자료로 계정 개통 흐름을 끝까지 돌렸다. 사원현황, 계정 39개, 초대 링크, 첫 비밀번호, 로그인, 로그아웃 뒤 쿠키 막기, 429 까지 된다. 운영 흐름, 권한과 개인정보, 숫자 대조, 휴대폰 화면 44장도 통과했다. 시험은 `tests/test_s3_verify.py` 다. 검증에서 찾은 접근 기록의 초대 토큰, 평문 백업, GET 로그아웃을 고쳤다. 5장의 S3 기준인 실제 계정 개통은 실제 배포 D-14 뒤에 한다. 계정의 바탕인 실제 사원현황은 D-02 로 받았다. 대표님이 우선 완성하자고 하셔서 새 질문 D-51 에서 D-60 은 제안대로 만들고 가정으로 표시했다.

S4 는 11월 15일에 개발을 마쳤고 검증을 통과했다. 개발 커밋은 b2b7d42, d91a047 이고 검증과 고침은 730c328, 1a59b6a, 21d995c, e698105 다. 된 것은 I 제도의 엔진과 화면 여섯 개, J 의 영업 화면과 팀 코칭과 상담 신청 랜딩, K 의 앱 AI 바탕과 7나이츠 심사와 AI 화면이다. 검증은 제작지침 D-66 과 API 키 D-26 이 있어야 하는 것을 빼고 했다. 상담 신청에서 배정, 활동, 고객 전환까지 이어진다. AI 심사, 회전, 결재, 기록이 된다. 권한, 개인정보, 한도, 휴대폰 화면 58장도 통과했다. 시험은 `tests/test_s4_verify.py` 다. 인증 실적은 D-33 가정 때문에 실적 요약과 다르고, 화면에 기준 설명이 있다. 검증 뒤 AI 환경 변수의 빈 값과 이상한 값, 가림 규칙, 허용 숫자, 심사되지 않은 마지막 고침의 승인, 접근 기록의 접속 주소를 고쳤다. 환경 변수는 `11_개발구조.md` 6장, 나머지 규칙은 `09_기능기획서.md` 9장과 `13_AI운영설계.md` 1.4 다. 심사되지 않은 고침은 결재 화면에서 확인해야 승인된다. 남은 것은 리포트와 카드뉴스의 제작지침 D-66, 7나이츠 여섯 자리 명세 D-65, 실제 API 키와 월 한도 D-26, 상담 신청 공개의 준법 확인과 광고 심의 D-29, 노션 연결 D-13 이다. 5장의 S4 기준인 배정에서 리포트까지 한 건 잇기는 제안 리포트를 만든 뒤에 한다. S4 에 새로 생긴 질문 D-61 에서 D-68 은 지금 동작대로 두고 가정으로 표시했다.

S1 에서 남은 기준은 지금 조직의 걸러 내지 않은 계약현황으로 하는 계약 단위 대조다. D-69 다. 실제 조직 트리는 사원현황으로 확인했다. 대조에 쓴 임시 DB 를 지울지는 D-75 다.

### 6.4 인프라와 배포

- 목표는 컨테이너 하나, 관리형 PostgreSQL, 객체 저장소, 도메인과 HTTPS 다. 서버 위치와 비용은 D-14 다. 실제 배포는 아직 하지 않았다.

- 올릴 때마다 자동 시험, 코드 점검, 컨텍스트 점검을 돌린다. 시험용에 자동 배포하는 일은 D-14 뒤에 붙인다.

| 단계 | 할 일 | 지금 |
| --- | --- | --- |
