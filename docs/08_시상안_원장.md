# 08. 시상안 원장

보험사별 시상안 엑셀을 원문 그대로 쌓고, 줄마다 해석 초안을 붙이는 자리다.
시상 공문 PDF(07 문서)가 구간표 한 장을 규칙으로 바꾸는 흐름이라면, 시상안 원장은 한 달 치 전 보험사 시상안을 한 번에 받아 두는 흐름이다.

## 1. 흐름

1. 시상안 엑셀을 올린다. 표준 양식은 `보험사 · 시상대상 · 분류 · 기간 · 달성기준 · 시상내용` 여섯 열이다.
2. `incentive_plan_doc` 에 파일 한 건, `incentive_plan_line` 에 줄마다 한 행이 쌓인다. 원문은 `*_raw` 열에 그대로 둔다.
3. 줄마다 수령 계층, 기간(일 단위), 유형, 지급 시점, 지급률 조각을 해석한다. 해석 결과는 초안(`review_status = draft`)이다.
4. 담당자가 화면에서 원문과 대조해 승인한다. 승인한 줄만 계산 규칙으로 넘긴다.
   정률 시책은 `commission_rate_rule` 의 `promo` 유형으로, 가동 · 연속가동 · 구간은 `incentive_rule` 로 간다. 규칙 변환은 아직 만들지 않았다.

## 2. 해석 항목

| 항목 | 값 | 근거 |
| --- | --- | --- |
| 수령 계층 `recipient_level` | ga / hq(총괄) / branch(지사) / fc / note(비고) | 시상대상 열 |
| 기간 `period_from` `period_to` | YYYY-MM-DD | 기간 열. 창이 둘 이상이면 비워 두고 사유를 남긴다 |
| 유형 `line_kind` | rate_promo / activity / consecutive / tier / note / unknown | 분류 열의 낱말과 시상내용의 지급률 |
| 지급 시점 `pay_timing` | next_month / inst13 / next_month+inst13 / year1 / year2 / unspecified | 익월, 13회차, 1차년, 2차년 표기 |
| 지급률 조각 `incentive_plan_component` | 기준 보험료 × 지급률 @ 지급 시점 | 시상내용의 `월초P * 50%(13회차 지급)` 꼴 |

`parse_status` 가 `auto` 인 줄은 시상내용의 퍼센트가 모두 지급률 조각으로 읽힌 정률 시책이다.
`manual` 은 사람이 봐야 하는 줄이고 `parse_note` 에 이유가 적힌다. 조건이 여럿인 지급률, 한도·조건부 지급률, 금액이 원본의 표나 그림에만 있는 줄, 기간 창이 둘 이상인 줄이 여기에 든다.

## 3. 읽는 방법 두 가지

- `read_xlsx` : 엑셀을 직접 읽는다. 병합 셀은 왼쪽 위 값만 오므로 보험사 · 시상대상 · 분류 · 기간을 위 줄 값으로 채운다. 표준 머리글이 없는 시트는 적재하지 않고 사유를 남긴다.
- `read_drive_extract` : 구글 드라이브 본문 추출본에서 표를 복원한다. 원본 엑셀을 내려받을 수 없을 때만 쓴다. 줄바꿈과 행 번호가 사라지고 그림은 오지 않는다.

## 4. 실행

```
python run_demo.py                                         # 샘플 시상안(samples/excel/202610_보험사별_시상안.xlsx)까지 적재
python -m app.loader.incentive_plan <파일> <YYYYMM>        # 시상안 한 건을 data/demo.db 에 적재하고 요약 출력
```

화면에서는 `데이터 수집 > 보험사별 시상안` 탭에서 올리고, 줄을 걸러 보고, 승인한다.
실제 시상안 파일은 `data/raw/` 아래에만 두며 저장소에 올리지 않는다.
