# 04. 점검(대사) 체크리스트

## 1. 수수료 대사

### 매칭 방법
1. 매칭 키: (보험사, 증권번호 정규화값, 수수료유형, 회차)
2. 보험사가 회차를 안 주면 (보험사, 증권번호, 수수료유형, 정산월)로 1단계 낮춰 매칭
3. 그래도 안 되면 (보험사, 증권번호)로 금액 합계 비교 후 `rounding` 또는 `unmatched`로 분류
4. 허용 오차: 라인당 ±10원, 설계사 월 합계 ±100원 (설정값)

### 차이 유형과 원인
| 유형 | 의미 | 흔한 원인 | 1차 조치 |
|------|------|-----------|----------|
| rate | 같은 기준금액인데 요율이 다름 | 수수료율표 미갱신, 상품군 규칙이 상품 규칙을 덮음, 보험사 시책 변경 | 보험사 공문 확인 → 규칙 추가 (적용 기간 지정) |
| conversion | 기준금액(환산P)이 다름 | 환산율 오류, 납입방식 월납 환산 오류, 보험료 변경(감액) 미반영 | 상품 마스터 환산율, 계약 보험료 재확인 |
| status_mismatch | 내부는 유지인데 보험사는 실효/해지 (또는 반대) | 유지현황 파일 미반영, 기준일 차이 | 유지현황 재적재, 상태 이력 확인 |
| missing_contract | 보험사 정산서에 있는 계약이 내부 원장에 없음 | 신계약 파일 누락, 증권번호 변경(전환), 타 대리점 코드 혼입 | 신계약 파일 확인, 수기 계약 등록 |
| insurer_only | 보험사만 지급 (내부 계산 없음) | 시책/프로모션 미등록, 소급 지급, 과거 월 정정 | 시책 규칙 등록 또는 보정 레코드 |
| internal_only | 내부만 계산 (보험사 미지급) | 보험사 지급 보류(미수금), 환수 상계, 초회보험료 미입금 | 보험사 문의, 미수 목록 관리 |
| clawback | 환수 금액 불일치 | 환수 비율표 차이, 경과 회차 계산 기준 차이 | 환수 규칙 확인 |
| rounding | 원 단위 절사 차이 | 보험사 절사 방식 | 허용 오차 내면 자동 ignore |

### 처리 흐름
```
open → (담당자 확인) → confirmed(보험사가 맞음, 내부 규칙 수정)
                    → adjusted(내부가 맞음, 보험사에 이의 제기 + 보정 레코드)
                    → ignored(허용 오차 또는 설명 가능한 일시 차이)
```
모든 전이에 메모와 근거(공문, 메일, 화면 캡처 경로)를 남긴다.

### 월 대사 요약 지표
- 보험사별 일치율 = 일치 라인 수 / 전체 라인 수
- 미처리 차이 금액 합계 (절대값)
- 유형별 건수 추이 (같은 유형이 3개월 연속이면 규칙/매핑 문제)

## 2. 구간시상 점검

| 항목 | 확인 방법 |
|------|-----------|
| 측정 지표 집계 범위 | 규칙의 scope(전체/보험사/상품군)와 제외 상품 조건이 집계 쿼리에 반영됐는지 샘플 설계사 3명 수기 계산 |
| 업적 귀속 월 | 월말 성립 건이 당월/익월 어디에 들어갔는지 (perf_date 정책) |
| 자격 조건 | 미자격 설계사 목록에서 사유별 건수 확인, 경계값(유지율 84.9% vs 85.0%) 샘플 |
| 구간 경계 | min/max 경계값 포함 여부 (300만 "이상" vs "초과") 규칙 문서와 대조 |
| 조직 이동자 | 월 중 이동한 설계사는 어느 조직 시상에 들어가는지 (소속 이력 기준일) |
| 신규 위촉자 특례 | tenure_months 조건이 위촉일 기준으로 맞게 계산되는지 |
| 시상 환수 | 시상 대상 계약이 감시 기간 내 해지된 경우 환수액 비례 계산 확인 |
| 중복 시상 | 같은 계약이 두 규칙에 동시에 들어가는 게 의도인지 |
| 전월 대비 | 총 시상액, 구간별 인원 분포 변동 사유 |

## 3. 업적 점검

| 항목 | 확인 방법 |
|------|-----------|
| 건수 대조 | 보험사 신계약 현황 건수 = 내부 원장 당월 신규 건수 |
| 환산P 합계 | 보험사 제공 환산 실적(있는 경우)과 내부 환산P 합계 비교 |
| 상태 분포 | 유지/실효/해지/철회 건수가 보험사 유지현황과 일치 |
| 설계사 매핑 | 미매핑 설계사 코드 0건 (미매핑 실적은 "미배정" 설계사로 모임) |
| 조직 집계 | 조직별 합계 = 소속 설계사 합계 (이력 기준일 일치) |
| 유지율 | 분모(대상 계약 수)와 분자(유지 계약 수) 정의가 보험사 기준과 같은지 |

## 4. 마감 전 최종 점검

```
[ ] 품질 이슈 차단 등급 0건
[ ] 대사 차이 open 0건
[ ] 설계사별 수수료 합계 음수 건 확인 (환수 > 지급) 및 이월 처리
[ ] 전월 마감 스냅샷과 이번 달 보정 레코드 연결 확인
[ ] 마스터 변경 이력(수수료율, 환산율, 시상 규칙) 이번 달 변경분 승인자 확인
[ ] 명세서 샘플 3건 수기 검산
```
