# 05. 확장 기능: 시상 PDF, 본부 단위 업로드, 업적 주기, 커리어패스, 인증 관리

| 요구 | 가능 여부 | 처리 방식 요약 |
|------|-----------|----------------|
| 시상 구간을 PDF로 읽어 월별 관리 | 가능 | PDF 보관 → 표 자동 추출 → 담당자 확인 화면 → 승인 시 해당 월 규칙으로 활성화 |
| 본부 단위 계약 엑셀 업로드, 청약·철회 걸러내기 | 가능 | 본부별 업로드 권한, 청약→성립→철회 상태 흐름, 성립 건만 확정 업적 |

## 1. 시상 구간 PDF → 월별 규칙

### 흐름
```
보험사 시책 공문 PDF / 내부 시상 안내 PDF 수신
  │
  ▼
[1] incentive_source_doc 등록  (보험사, 대상 월, 파일 경로, 해시, 수신일)
  │
  ▼
[2] 표 추출
    - 텍스트 PDF: pdfplumber / camelot 로 표 영역 추출
    - 스캔 PDF:   OCR(tesseract 한글) 후 표 재구성, extraction_method = 'ocr'
    - 추출 실패:  담당자가 수기 입력, extraction_method = 'manual'
  │
  ▼
[3] 초안 규칙 생성  incentive_rule(status='draft') + incentive_tier + incentive_condition
  │
  ▼
[4] 검토 화면     PDF 원본 미리보기 ↔ 추출된 구간표 나란히 표시, 수정 후 승인
  │
  ▼
[5] 승인          status='active', effective_from = effective_to = 대상 월
```

### 운영 규칙
- **100% 자동은 아니다.** 보험사마다 공문 양식이 다르고 "이상/초과", "환산P/월납P" 같은 표현 차이가 금액을 바꾼다. 추출 결과는 반드시 사람이 승인한 뒤에만 계산에 쓰인다.
- 같은 월에 수정 공문이 오면 새 `incentive_source_doc` + 새 규칙 버전(`version` +1)을 만들고 이전 규칙은 `retired`. 이미 계산한 결과가 있으면 재계산 실행을 안내한다.
- 보험사 시책(insurer_id 있음)과 내부 시상(insurer_id NULL)을 같은 구조로 관리하되 화면에서 구분한다.
- PDF 원본은 `raw/{보험사}/{YYYY}/{YYYYMM}/{YYYYMM}_{보험사}_incentive_v{n}.pdf`에 보관하고, 규칙 레코드가 `source_doc_id`로 원본을 가리킨다.
- 템플릿 `templates/10_시상구간_추출결과.csv`가 추출 결과(또는 수기 입력)의 표준 형태다.

### 추출 시 자주 틀리는 부분 (검토 화면에서 강조 표시)
| 항목 | 예 |
|------|----|
| 경계 포함 여부 | "300만 이상" vs "300만 초과" |
| 측정 지표 | 환산P / 월납P / 연납P / 건수 |
| 단위 | 만원 / 천원 / 원 |
| 보상 방식 | 정률(%) / 정액(원) / 환산P 배수 |
| 자격 조건 | 유지율, 최소 건수, 신규 위촉자 특례, 제외 상품 |
| 환수 조건 | 시상 후 N개월 내 해지 시 환수 비율 |

## 2. 본부 단위 계약 엑셀 업로드와 청약·철회 필터

### 업로드
- 메뉴: 데이터 수집 → 본부 계약 업로드. 업로드자의 소속 본부가 자동으로 `import_batch.upload_org_id`에 기록된다.
- 권한: 본부 담당자는 자기 본부만 업로드·조회, 본사 정산 담당은 전체.
- 템플릿: `templates/11_본부계약업로드.csv`. 청약번호, 증권번호(성립 전이면 공란), 보험사, 상품, 설계사 사번, 청약일, 성립일, 상태, 철회일, 보험료.
- 같은 청약번호가 다시 올라오면 상태 변화만 `contract_status_history`에 추가한다 (예: 지난주 청약 → 이번 주 성립).

### 상태 흐름과 집계 규칙
```
applied(청약) ──▶ inforce(성립/승인) ──▶ lapsed / cancelled / matured
     │                 │
     ├──▶ withdrawn(청약철회)
     └──▶ declined(반송/거절)
```

| 상태 | 업적 집계 | 수수료 | 시상 |
|------|-----------|--------|------|
| applied (청약) | **예정 업적**으로만 표시, 확정 집계 제외 | 없음 | 없음 |
| inforce (성립) | 확정 업적, `perf_ym`에 귀속 | 계산 | 대상 |
| withdrawn (철회) | 제외. 이미 집계된 월이면 **철회 월에 차감 보정** | 지급분 환수 | 시상 환수 |
| declined (반송) | 제외 | 없음 | 없음 |
| lapsed / cancelled | 집계는 유지, 유지율 분자에서 제외 | 환수 규칙 적용 | 환수 감시 기간 내면 시상 환수 |

- 업적 기준일(`perf_date`) 정책은 **성립일** 기본, 회사 정책에 따라 초회보험료 입금일로 바꿀 수 있다.
- 철회 가능 기간(청약일 기준 보험사별 N일) 안의 성립 건은 화면에서 "철회 가능" 표시를 해 둔다.
- 본부 업로드 데이터와 보험사 신계약 현황을 매월 대조한다. 본부에만 있는 건(보험사 미반영), 보험사에만 있는 건(본부 누락)을 `reconciliation_diff` 와 같은 방식으로 목록화한다.

## 3. 월 · 분기 · 반기 · 연 업적

### 기간 키
| period_type | period_key 예 | 범위 |
|-------------|---------------|------|
| month | `202610` | 해당 월 |
| quarter | `2026Q4` | 10~12월 |
| half | `2026H2` | 7~12월 |
| year | `2026` | 1~12월 (회계연도 설정 시 시작 월 변경 가능) |

### 집계 테이블 `agent_performance_summary`
설계사 × 기간 유형 × 기간 키 단위로 다음을 저장한다.
- 청약 건수(applied_count), 성립 건수(new_count), 철회 건수(withdrawn_count), 순 건수(net_count)
- 월납보험료 합, 환산보험료 합
- 수수료 합, 환수 합
- 기준일 소속 조직(`org_id`)

월 집계가 확정되면 분기·반기·연은 월 집계를 합산해 만든다. 조직 집계는 같은 테이블을 `org_id`로 묶어 뷰로 제공한다.

### 구간시상 규칙의 기간 확장
`incentive_rule.period_type`에 `half`, `year`를 추가했다. 분기 시상은 분기 집계를, 반기 시상은 반기 집계를 지표로 쓴다.

## 4. 커리어패스 목표 관리

### 구성
| 테이블 | 역할 |
|--------|------|
| `career_level` | 직급 체계 (예: FC → SFC → SM → BM → 본부장), 순서 |
| `career_promotion_criteria` | 승격 기준: 어떤 직급에서 어떤 직급으로, 어떤 지표가 어떤 기간에 얼마 이상 |
| `agent_career_history` | 설계사 직급 이력 (적용 시작·종료, 사유, 승인자) |
| `agent_goal` | 개인 목표: 기간 × 지표 × 목표값, 설정자(본인/조직장) |

### 기능
- **목표 대비 진척률**: `agent_goal.target_value` 대비 `agent_performance_summary` 실적. 월 중에는 일할 추세로 달성 예상치를 함께 표시한다.
- **승격 후보 자동 추출**: 매월 집계 후 `career_promotion_criteria`를 전 설계사에 대입해 "조건 충족" 목록을 만든다. 승격은 사람이 승인하고 `agent_career_history`에 기록한다.
- **커리어 로드맵 화면**: 현재 직급, 다음 직급까지 남은 조건별 격차(예: 분기 환산P 200만 부족, 유지율 충족).
- 승격 기준도 `effective_from`/`effective_to`를 가져 제도 변경 전후를 함께 보관한다.

## 5. 우수인증설계사 · MDRT 관리

### 구성
| 테이블 | 역할 |
|--------|------|
| `certification_program` | 프로그램 정의: MDRT, COT, TOT, 우수인증설계사(생보), 우수인증설계사(손보), 사내 인증 |
| `certification_criteria` | **연도별** 기준: 지표, 연산자, 값. 매년 공식 공고 값을 입력 |
| `agent_certification_status` | 설계사 × 프로그램 × 연도 진척: 지표별 현재값, 달성 여부, 진척률, 달성 예상 |
| `agent_certification_award` | 실제 인증·수상 기록 (수여일, 인증번호, 증빙 경로) |

### 운영 규칙
- **기준 값은 코드에 넣지 않는다.** MDRT 한국 기준(수수료 기준, 보험료 기준, 소득 기준)과 협회 우수인증설계사 기준은 해마다 바뀌므로 매년 초 `certification_criteria`에 공식 공고 값을 입력하고 근거 문서를 연결한다.
- 지표 종류: 연 누적 수수료, 연 누적 초회보험료, 13회차·25회차 유지율, 근속 개월, 불완전판매 건수, 민원 건수, 완전판매 교육 이수 여부.
- 진척 계산은 월 마감 때 자동 실행하고, "현재 추세 유지 시 달성 예상 월"을 함께 보여 준다.
- 불완전판매·민원 건수처럼 외부(보험사·협회)에서 오는 지표는 `templates/12_외부지표.csv` 형태로 업로드한다.
- 달성자 목록은 연말 신청용 자료로 내보낼 수 있게 설계사·프로그램·지표값·증빙을 한 화면에 모은다.

## 6. 추가되는 화면

```
데이터 수집
├─ 본부 계약 업로드 (본부별)            ← 신규
├─ 시상 공문 PDF 등록 / 추출 결과 검토   ← 신규
└─ 외부 지표 업로드 (불완전판매·민원)     ← 신규

업적
├─ 기간별 실적 (월 / 분기 / 반기 / 연)   ← 확장
├─ 청약 현황 (예정 업적, 철회 가능 건)    ← 신규
└─ 본부 업로드 ↔ 보험사 현황 대조         ← 신규

커리어패스                                ← 신규
├─ 직급 체계 / 승격 기준
├─ 개인 목표 설정·진척
└─ 승격 후보

인증 관리                                 ← 신규
├─ 프로그램 / 연도별 기준
├─ 설계사별 진척 (MDRT, 우수인증)
└─ 수상 기록
```

| 2. 업적 | 월·분기·반기·연 집계 테이블, 예정 업적 화면 |
