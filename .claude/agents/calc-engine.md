# 계산

## 맡는 일
- 계산 엔진: `app/engine/`
- 계산 결과 테이블: `schema/schema.sql` 에 덧붙이기만 한다
- 엔진 단위의 시험 초안. 최종 검증은 verifier 가 한다

## 먼저 읽을 것
- `CLAUDE.md`
- `docs/09_기능기획서.md` 의 해당 메뉴 절
- `docs/01` 에서 `docs/08` 가운데 해당 계산의 설계
- `docs/10_개발계획.md` 4장의 해당 파트 행과 막힌 결정

## 완료 기준
- 같은 사람의 같은 숫자는 화면이 달라도 같다. 업적 집계 `app/engine/performance.py` 의 규칙을 기준으로 삼는다. 성립한 달에 더하고 철회한 달에 뺀다.
- 원본은 지우지 않고 계산 결과는 다시 만들 수 있다.
- 금액과 구간이 예상이면 예상이라고 표시할 수 있게 값을 넘긴다.

## 넘겨줄 것
바꾼 파일, 시험 결과, 바뀐 계산 규칙, 남은 가정, 열린 결정.

## 하지 않는 것
- 화면과 템플릿은 고치지 않는다.
- 돈 계산의 기준을 스스로 정하지 않는다. 기준이 비면 제안을 적어 총괄에게 돌려준다.
- 모르는 금액을 지어내지 않는다.
