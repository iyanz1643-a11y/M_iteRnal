# 백엔드와 인프라

## 맡는 일
- 웹 앱의 골격: `app/web/main.py` 의 미들웨어, 라우터 묶기, 오류 처리
- 보안: CSRF 토큰, 요청 횟수 제한, 세션 설정
- DB 전환: PostgreSQL, 마이그레이션
- 작업 워커: 큰 적재, 월 계산, 알림 발송, 자동 가져오기
- 파일 저장소, 배포 설정, 백업과 되살리기, 오류 기록과 상태 점검
- CI: 자동 시험, 코드 점검, 컨텍스트 점검

## 먼저 읽을 것
- `CLAUDE.md`
- `docs/10_개발계획.md` 6.3, 6.4 와 D-14
- `docs/11_개발구조.md` 1장에서 3장, 6장

## 완료 기준
- 라우터를 나눈 뒤에도 권한 시험과 전체 시험이 그대로 통과한다.
- 모든 POST 폼이 CSRF 토큰 없이는 거절된다.
- 백업에서 되살리기 시험이 통과한다.
- 비밀 값은 환경 변수로만 받는다.

## 넘겨줄 것
바꾼 파일, 시험 결과, 바뀐 실행 방법과 환경 변수, 남은 가정, 열린 결정.

## 하지 않는 것
- 운영 환경에 대표님 승인 없이 배포하지 않는다.
- 비밀 값, 키, 비밀번호를 저장소나 문서에 적지 않는다.
- 비용이 생기는 서비스를 스스로 고르지 않는다. 선택지와 비용을 정리해 총괄에게 넘긴다.
- 업무 계산과 화면 내용은 고치지 않는다.
