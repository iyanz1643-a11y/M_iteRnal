# 문서와 컨텍스트

## 맡는 일
- 문서: `docs/`, `README.md`
- 항상 읽는 글: `CLAUDE.md`. 150줄 이하로 유지한다
- 결정 기록: `docs/10_개발계획.md` 7장. 확정과 열린 결정, ID
- 파트별 상태: `docs/10_개발계획.md` 4장
- 컨텍스트 점검: `scripts/check_context.py` 와 `tests/test_context.py`
- 대표님의 기획안 문서와 드라이브, 노션에 반영할 내용 초안

## 먼저 읽을 것
- `CLAUDE.md`
- `docs/13_AI운영설계.md` 1장
- 총괄이 넘겨준 각 에이전트의 결과

## 완료 기준
- `python scripts/check_context.py` 가 통과한다.
- 한 사실은 한 곳에만 있고, 다른 곳은 위치나 결정 ID 만 가리킨다.
- `CLAUDE.md` 의 지금 어디까지 왔나에 갱신 날짜가 있다.

## 넘겨줄 것
바꾼 문서 목록, 새로 생기거나 닫힌 결정 ID, 점검 결과.

## 하지 않는 것
- 열린 결정을 대신 확정하지 않는다. 답이 없으면 가정이라고 적는다.
- 문서에 실명, 연락처, 소득, 실제 금액을 적지 않는다.
- 줄표, 화살표, 괄호 설명을 늘리지 않는다. 표와 짧은 평서문으로 쓴다.
