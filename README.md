# M_iteRnal — 보험 GA 수수료·구간시상·업적관리 앱

보험대리점(GA)이 여러 보험사로부터 받는 **수수료 정산서**, 내부 **구간시상(인센티브)**, 설계사(FC) **업적**을
한 곳에서 관리하고, 보험사 정산 금액과 내부 계산 금액을 **대사(점검)** 하기 위한 앱의 설계 문서와 기초 자산입니다.

## 핵심 원칙

1. **원본은 손대지 않는다.** 보험사에서 받은 파일은 그대로 보관하고, 모든 가공은 별도 계층에서 한다.
2. **모든 숫자는 근거가 있다.** 수수료·시상 금액 한 줄마다 어떤 계약, 어떤 규칙, 어떤 원본 파일에서 왔는지 추적된다.
3. **마감된 월은 바꾸지 않는다.** 수정이 필요하면 보정 레코드를 추가한다.
4. **보험사마다 다른 형식은 매핑으로 흡수한다.** 앱 내부는 하나의 표준 스키마만 안다.

## 시작하기 (샘플 데이터로 바로 실행)

```bash
pip install -r requirements.txt
python run_demo.py          # 샘플 엑셀·PDF 생성 → 적재·추출 → 202601~202610 수수료·업적·시상·랭킹·대사·인증 계산
streamlit run app/ui.py     # 화면 열기
```

자세한 내용은 `docs/01_앱구성.md`부터 읽으면 됩니다.
